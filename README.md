# Safe Signal — Cyber Safety Awareness Quiz

A small, static website prototype for a college cyber-safety field project. It has a six-question baseline check, three short learning cards, a six-question after-lesson check with explanations, and a score comparison.

## Run it

Open `index.html` in a modern browser. The site uses only HTML, CSS and JavaScript, has no external libraries, and needs no build step or server. It can also be placed on a static website host.

## Privacy

There is no login, analytics, server or collection of personal details. The current activity’s answers and scores are stored in the browser’s local storage so the activity can resume on that device. Use **Start over** to clear the activity state. After finishing, participants can download an anonymous CSV summary containing only the number correct before and after and the score change. Combine those files in a spreadsheet for a simple group summary; they contain no names, dates or answer choices. Gather any written feedback separately and anonymously. On a shared device, use **Start over** between participants.
